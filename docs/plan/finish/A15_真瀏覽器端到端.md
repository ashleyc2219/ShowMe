## 4. 名詞小抄

| 名詞 | 白話解釋 |
|---|---|
| headless | 瀏覽器「沒有視窗」地跑。測試用 headless（快、CI 友善）；**demo 一定要 headed**，因為人得看見箭頭。 |
| `add_init_script` | Playwright 的 context 設定：每次頁面建立或導航，在 document 建好、頁面自己的 script 跑之前，先注入一段 JS。所以 reload 之後 `window.__showme` 仍然在。 |
| `expose_function` | 在頁面的 `window` 上掛一個函數；頁面呼叫它時，實際執行的是 Python 這邊的 callback。這就是 overlay 叫醒 `show_step` 的橋。掛在 **context** 上（不是 page），跨 page／導航都在。 |
| `page.evaluate(expr, arg)` | 在頁面裡執行一段 JS 並把可序列化的結果拿回 Python。我們用它做「檢查」（讀 `dataset`）與「模擬」（呼叫 `__showme_emit`）。 |
| `dataset.showmeShowing` | HTML 的 `data-showme-showing` 屬性在 JS 裡的存取方式。`data-` 後面的 kebab-case 會變成 camelCase：`data-showme-showing` → `dataset.showmeShowing`。 |
| `static_server` fixture | conftest 起的一個小 HTTP server（Python 內建 `http.server`，跑在背景 thread、隨機 port），把 `tests/fixtures/pages/` 端出去。yield 出來的是 `http://127.0.0.1:{port}`。 |
| `@pytest.mark.browser` | 我們自訂的 marker，標記「這個測試會開真瀏覽器」。`uv run pytest -m "not browser"` 可以跳過全部。 |
| 輪詢（polling） | 「每隔一小段時間問一次，直到條件成立或超時」。瀏覽器操作有真實的 IO 延遲，`await asyncio.sleep(0)` 讓一下是不夠的，要輪詢。 |
| `app._browser` | `ShowMeApp` 內部持有的 `BrowserLike`。測試直接摸這個私有屬性去拿 Playwright 的 `page`——這是**測試才做的事**，產品程式碼不會這樣用。 |

## 7. 步驟

### Step 1：寫測試檔

建立 `tests/test_e2e_fake_overlay.py`，整份貼上：

```python
"""A15：真瀏覽器端到端（Python 側）。

開一顆真的 headless Chromium，注入「A 側的測試替身」fake_overlay.js，
走完 start_tutorial → show_step(step_done) → end_tutorial → 再 end_tutorial。

⚠️ tests/fixtures/fake_overlay.js 不是 B 的產品 overlay。
   它只實作 window.__showme 的四個方法、不畫 Driver.js 箭頭、不自己判定完成；
   emit 由測試用 page.evaluate 手動觸發。
   要驗 B 的真 overlay 走完整條流程，看 tests/test_e2e_real_overlay.py。
"""

from __future__ import annotations

import asyncio
from pathlib import Path

import pytest

from showme.app import ShowMeApp
from showme.browser import PlaywrightBrowser
from showme.session import DONE_BANNER_TEXT, STEP_NEXT_ACTION, State

pytestmark = [pytest.mark.anyio, pytest.mark.browser]

FAKE_OVERLAY = Path(__file__).parent / "fixtures" / "fake_overlay.js"


@pytest.fixture
async def e2e_app():
    """一個用真 PlaywrightBrowser（headless + 假 overlay）的 ShowMeApp。

    每個測試各拿一顆自己的瀏覽器，測完一定關掉。
    """
    app = ShowMeApp(
        browser_factory=lambda: PlaywrightBrowser(
            overlay_path=FAKE_OVERLAY, headless=True
        )
    )
    try:
        yield app
    finally:
        await app.shutdown()


def _uid_of(page: dict, name: str) -> str:
    """從 page.elements 裡照 a11y name 找 uid。不要在測試裡硬寫 's1-1'。"""
    return _element_of(page, name)["uid"]


def _element_of(page: dict, name: str) -> dict:
    for element in page["elements"]:
        if element["name"] == name:
            return element
    raise AssertionError(f"page.elements 裡找不到 name={name!r}：{page['elements']}")


async def _wait_until_showing(page, uid: str, timeout_s: float = 5.0) -> None:
    """輪詢等到 body 的 data-showme-showing 變成這個 uid。

    show() 要跨行程送到瀏覽器再執行，有真實的 IO 延遲，
    所以不能只用 await asyncio.sleep(0) 讓一下就假設它畫好了。
    """
    loop = asyncio.get_running_loop()
    deadline = loop.time() + timeout_s
    seen = None
    while loop.time() < deadline:
        seen = await page.evaluate("() => document.body.dataset.showmeShowing || ''")
        if seen == uid:
            return
        await asyncio.sleep(0.05)
    raise AssertionError(
        f"等了 {timeout_s} 秒，body 的 data-showme-showing 還是 {seen!r}，不是 {uid!r}"
    )


async def _read_banner(page) -> str | None:
    return await page.evaluate(
        "() => { const el = document.getElementById('showme-banner');"
        " return el ? el.textContent : null; }"
    )


# --------------------------------------------------------------------------
# 主線：start → show_step（人做完）→ end → 再 end
# --------------------------------------------------------------------------

async def test_end_to_end_happy_path(e2e_app, static_server):
    app = e2e_app
    url = f"{static_server}/dashboard.html"

    # ---- start_tutorial：開頁、注入 overlay、拍第一份 snapshot ----
    start = await app.start_tutorial(url, "create a project")

    assert start["error"] == ""
    assert start["goal"] == "create a project"
    assert start["session_id"].startswith("s_")

    page_data = start["page"]
    assert page_data["url"].endswith("/dashboard.html")
    assert page_data["title"] == "Dashboard"
    assert page_data["truncated"] is False

    new_project = _element_of(page_data, "New Project")
    settings = _element_of(page_data, "Settings")
    assert new_project["role"] == "button"
    assert new_project["testid"] == "new-project"
    assert settings["role"] == "link"
    assert settings["testid"] == "", "沒有 data-testid 時鍵仍在、值是空字串"
    assert all(el["uid"].startswith("s1-") for el in page_data["elements"])

    uid = new_project["uid"]
    browser_page = app._browser.page   # 測試才這樣摸私有屬性，產品程式碼不會

    # ---- show_step：畫出來、卡住等 emit ----
    task = asyncio.create_task(
        app.show_step(
            start["session_id"], uid, "Click New Project", "click", 1, 3, timeout_s=5
        )
    )
    await _wait_until_showing(browser_page, uid)

    assert not task.done(), "show_step 應該還卡在等 emit"
    assert app.store.current().state is State.SHOWING
    assert app.store.current().steps_shown == 1

    # ---- 模擬「人做完了」：頁面呼叫 window.__showme_emit ----
    await browser_page.evaluate(
        "() => window.__showme_emit({kind: 'step_done', url: location.href, ts: Date.now()})"
    )
    result = await task

    assert result["event"] == "step_done"
    assert result["error"] == ""
    assert result["signal"] == ""
    assert result["next_action"] == STEP_NEXT_ACTION
    assert isinstance(result["elapsed_s"], float)
    assert all(el["uid"].startswith("s2-") for el in result["page"]["elements"]), (
        "show_step 回傳的一定是新一代 snapshot"
    )
    assert app.store.current().state is State.READY

    # ---- end_tutorial：清 overlay、貼固定 banner、刪 Session ----
    ended = await app.end_tutorial(start["session_id"], "invite a member")

    assert ended["ok"] is True
    assert ended["error"] == ""
    assert await _read_banner(browser_page) == DONE_BANNER_TEXT, (
        "banner 文案固定，summary（invite a member）不進橫幅"
    )
    assert await browser_page.evaluate(
        "() => document.body.dataset.showmeShowing || ''"
    ) == "", "end 之前先 clear()，箭頭標記要被拿掉"

    # ---- 再 end 一次：Session 已經刪掉了 ----
    again = await app.end_tutorial(start["session_id"], "invite a member")

    assert again["ok"] is False
    assert again["error"] == "session_not_found"
    assert app.store.current() is None

    # 瀏覽器還活著（A 的設計決定 A-2，可改）：人要留在畫面上看 banner
    assert not browser_page.is_closed()


# --------------------------------------------------------------------------
# 支線：沒有人來 emit，Python 這邊自己計時
# --------------------------------------------------------------------------

async def test_show_step_times_out_and_clears_the_overlay(e2e_app, static_server):
    app = e2e_app
    url = f"{static_server}/dashboard.html"

    start = await app.start_tutorial(url, "create a project")
    uid = _uid_of(start["page"], "New Project")
    browser_page = app._browser.page

    task = asyncio.create_task(
        app.show_step(
            start["session_id"], uid, "Click New Project", "click", 1, 3, timeout_s=0.5
        )
    )
    await _wait_until_showing(browser_page, uid)

    # 什麼都不做，等 Python 這邊的計時器到期
    result = await task

    assert result["event"] == "timeout"
    assert result["error"] == "", "timeout 是 event，不是 error"
    assert result["elapsed_s"] >= 0.5
    assert result["page"] is not None
    assert all(el["uid"].startswith("s2-") for el in result["page"]["elements"])
    assert app.store.current().state is State.READY

    # timeout 之後要清 overlay（A 的設計決定 A-3，可改）
    assert await browser_page.evaluate(
        "() => document.body.dataset.showmeShowing || ''"
    ) == ""
```

## 9. 常見問題與排錯

| 症狀 | 原因 | 怎麼處理 |
|---|---|---|
| `Executable doesn't exist at .../chrome-mac/...` | Chromium 沒裝 | `uv run playwright install chromium` |
| 測試在 `_wait_until_showing` 丟 `AssertionError: 等了 5 秒…還是 ''` | `fake_overlay.js` 的 `show()` 沒設 `document.body.setAttribute("data-showme-showing", opts.uid)`，或 `PlaywrightBrowser` 沒把 `overlay_path` 用在 `add_init_script` | 先手動確認：`uv run python -c "print(open('tests/fixtures/fake_overlay.js').read())"`；再回 A06 檢查 |
| `TypeError: 'NoneType' object has no attribute 'evaluate'`（`app._browser.page` 是 None） | `start_tutorial` 之前就去拿 `app._browser` | 一定要先 `await app.start_tutorial(...)`，`_ensure_browser()` 才會建瀏覽器 |
| `AttributeError: 'ShowMeApp' object has no attribute '_browser'` | A07 的骨架欄位名不同 | 照 brief §4.4：`self._browser: BrowserLike \| None = None` |
| `page.title == ""`，斷言 `== "Dashboard"` 失敗 | `dashboard.html` 沒有 `<title>Dashboard</title>` | 補進 A04 建的那個 fixture 檔（它本來就該有；spec 的 Example 用的就是 Dashboard） |
| `_element_of` 找不到 `New Project` | `dashboard.html` 的元素沒標 `data-role`，或文字有多餘空白 | fake_overlay 用 `textContent.trim()` 當 name；確認 HTML 裡按鈕文字就是 `New Project` |
| `testid` 是 `None` 而不是 `""` | `build_page` 沒補鍵，或 fake_overlay 回 `undefined` | `rules.build_page` 要把缺的鍵補成 `""`（A03）；fake_overlay 要寫 `el.dataset.testid \|\| ""`（A06） |
| `elapsed_s >= 0.5` 失敗，實際是 `0.5` 但比較是 `>` | 用了 `>` | 規格是 `>=`，用 `>=` |
| 測試跑完機器上留了一堆 Chromium 行程 | fixture 沒 `await app.shutdown()`，或測試中途丟例外時沒進 teardown | fixture 一定要寫成 `try: yield app / finally: await app.shutdown()` |
| 整個 test session 卡住被 pytest-timeout（60 秒）砍掉 | `create_task` 之後沒有人 emit、也沒設短的 `timeout_s`（於是用預設 120 秒，比 pytest 的 60 秒還久） | 主線測試一定要 emit；支線測試一定要傳 `timeout_s=0.5` |
| headless 跑得過、headed 跑不過 | 通常是視窗還沒獲得焦點／渲染慢 | 我們的斷言都不看畫面像素，只看 DOM，理論上不受影響；真的不穩就把 `_wait_until_showing` 的 `timeout_s` 調到 10 |
| `AssertionError` 說 `data-showme-showing` 在 `end_tutorial` 之後還在 | `end_tutorial` 沒呼叫 `clear()`，或 `clear()` 順序寫在 `done()` 之後 | 回 A13 檢查：先 `clear()` 再 `done()` |
| 想把這個測試改成用 `overlay/overlay.js`（B 的） | 那會讓 A 的迴歸網跟 B 的進度綁在一起 | 不要改。驗 B 的 overlay 是 A05 的 `test_browser_inject.py` 的工作 |

## 11. 附：真 overlay e2e（`tests/test_e2e_real_overlay.py`）

§7 的 `test_e2e_fake_overlay.py` 刻意把 overlay 換成 A 側替身，證明的是「**Python 這一半是好的**」。
這一節是**加碼**的第二個檔，把最後一層假的也換掉：`PlaywrightBrowser(headless=True)` **不傳 `overlay_path`**，
所以注入的就是 `showme/browser.py` 的預設值 `overlay/overlay.js`——B 的產品 overlay（含 vendor 進來的 Driver.js）。

兩個檔的差別只有一行，但意義完全不同：

```text
  test_e2e_fake_overlay.py                 test_e2e_real_overlay.py
  ────────────────────────                 ────────────────────────
  overlay_path=FAKE_OVERLAY                （不傳，用 overlay/overlay.js）
  show() 只寫一個 data 屬性                 show() 真的用 Driver.js 挖亮 + popover
  「人做完了」＝測試手動 page.evaluate       「人做完了」＝測試 page.click，
      window.__showme_emit(...)                overlay 自己聽 hashchange → 自己 emit
  → 驗 Python 半邊                          → 驗 S7：人做完，show_step 才回來
```

### 11.1 兩條測試

| 測試 | 走什麼 | 斷言重點 |
|---|---|---|
| `test_real_overlay_end_to_end_user_clicks_settings` | `start_tutorial` →（背景）`show_step(kind="click", timeout_s=5)` → **`page.click('a[href="#settings"]')`** → `end_tutorial` → 再 `end_tutorial` | 每個 element 都恰好有 `uid/role/name/testid` 四鍵且 uid 是 `s1-*`；`show_step` 在人點之前 `not task.done()`；點完回 `event == "step_done"`、`error == ""`、`page.url` 以 `#settings` 結尾、新 page 的 uid 是 `s2-*`；`end_tutorial` 後 `document.body.innerText` 含 `DONE_BANNER_TEXT`；再 end 是 `session_not_found` |
| `test_real_overlay_timeout_clears_without_error` | `show_step(kind="click", timeout_s=1)` 對 `New Project`，**什麼都不點** | `event == "timeout"`、`error == ""`（真 overlay 的 `clear()` 被呼叫不會炸）、`elapsed_s >= 1`、`.driver-popover` 已經不在 DOM 裡 |

### 11.2 兩個非做不可的等待

真 overlay 有 Driver.js，時序比假 overlay 複雜，所以測試不能只 `await asyncio.sleep(0)`：

1. `_wait_until_showing(app)`：輪詢 `app.store.current().state is State.SHOWING`（最多 2 秒）。
2. `_wait_for_highlight(page, console)`：輪詢 `document.querySelector('.driver-popover')` 出現（最多 3 秒）。
   **這一步才是關鍵**——`app.py` 是先把 state 設成 `SHOWING`、再 `await browser.show(...)`，
   所以只等 state 會在 overlay 還沒掛好完成條件的 listener 之前就去點，那一下點了不算。
   overlay 的 `show()` 是先 `driverObj.highlight()` 再 `observe()`，popover 出現就代表 listener 也掛好了。

另外每個測試都用 `page.on("console", ...)` 把頁面的 console 收進一個 list，
所有斷言訊息都把它帶上——真 overlay 若 vendor 沒串好（`Driver.js 沒有載入` / `driver.css 沒有內嵌進來`），
一眼就看得到，不用再開一次瀏覽器猜。
