## 1. 這一篇要做什麼

寫出 `showme/rules.py`：六個**純函數**，把規格裡那些「模型可能亂傳」與「overlay 可能少給」的狀況一次收乾淨——`timeout_s` 正規化成 120、非法 `kind` 一律當 observe、observe 沒帶 `expect_text` 要能被偵測、以及把 overlay 回來的原始 snapshot 補成標準 Page（補 `testid` 鍵、砍到 150、算 `truncated`）。

**純函數** = 給它同樣的輸入永遠得到同樣的輸出，不改任何外部狀態、不做 I/O。所以這個檔案不 import `session.py`、不 import `browser.py`，也不需要 async——是整套最容易測、也最不容易錯的一塊。

### 2.1 `build_page` 的資料流

```text
  overlay（B 的 window.__showme.snapshot(2)）回來的原始資料
  ┌────────────────────────────────────────────────────────────┐
  │ {"elements": [                                             │
  │     {"uid": "s2-1", "role": "button", "name": "Create",    │
  │      "testid": "create"},                                  │
  │     {"uid": "s2-2", "role": "link", "name": "Settings"},   │  ← 少了 testid
  │     … 一共 151 筆 …                                        │
  │   ],                                                       │
  │  "truncated": false}                                       │
  └───────────────────────────┬────────────────────────────────┘
                              │
   Python 這邊補上 url / title │  build_page(raw, url, title)
   （page.url、page.title()）  │  ① 只留前 150 筆
                              │  ② 每筆只留 uid/role/name/testid，缺的補 ""
                              │  ③ truncated = overlay 說的 OR 原本超過 150
                              ▼
  ┌────────────────────────────────────────────────────────────┐
  │ {"url": "http://localhost:3000/projects/new",              │
  │  "title": "New Project",                                   │
  │  "elements": [                                             │
  │     {"uid": "s2-1", "role": "button", "name": "Create",    │
  │      "testid": "create"},                                  │
  │     {"uid": "s2-2", "role": "link", "name": "Settings",    │
  │      "testid": ""},               ← 鍵永遠都在              │
  │     … 剛好 150 筆 …                                        │
  │   ],                                                       │
  │  "truncated": true}               ← 因為原本有 151 筆       │
  └────────────────────────────────────────────────────────────┘
                              │
                              ▼
              存進 session.latest_page，並原封不動回給 agent
```

## 4. 名詞小抄

| 名詞 | 白話解釋 |
|---|---|
| **純函數** | 給同樣的輸入永遠回同樣的輸出，而且不改外面任何東西（不寫檔、不改全域變數、不呼叫網路）。好處：測試不用準備環境，直接呼叫就好。 |
| **正規化（normalize）** | 把「各種可能的寫法」收斂成「一種標準寫法」。例如把 `None`、`0`、`-5` 都變成 `120.0`。 |
| **`kind`** | 這一步要人做的動作類型：`click`（點）、`input`（打字）、`select`（下拉選）、`observe`（等畫面出現某段文字）。它是**模型唯一能決定「怎樣算做完」的欄位**。 |
| **`expect_text`** | `observe` 這種步驟的完成條件：頁面出現這段文字就算做完。所以 observe 沒帶它就無法判定完成，必須當場失敗。 |
| **snapshot（快照）** | 把目前頁面上「可以互動的元素」掃成一張清單。掃一次叫一份 snapshot。 |
| **snapshot#（世代號）** | 第幾份快照。uid 長成 `s{世代}-{序號}`，所以 `s1-4` 是第 1 份的第 4 個。世代由 **Python 決定並傳給 overlay**。 |
| **`truncated`** | 這份清單有沒有被砍過。符合條件的元素超過 150 個時，只留前 150 並把它設成 `true`，agent 看到就知道「還有沒列出來的東西」。 |
| **a11y name** | 無障礙名稱：螢幕報讀器會念出來的那個名字（按鈕上的字、`aria-label`、`label`）。沒有的話值是空字串，元素**仍然要列出來**。 |
| **`data-testid`** | 前端常用來給測試抓元素的屬性。我們把它照抄進 `testid`；沒有就給空字串——**但鍵一定要在**。 |
| **DOM 走訪順序** | 從 HTML 由上到下、由外到內走一遍的順序。截斷就照這個順序取前 150，**不管元素有沒有在畫面可視範圍內**。 |
| **`bool(x)`** | 把任何值轉成 True／False。`bool(None)`、`bool("")`、`bool(0)` 都是 False。我們用它把 overlay 可能給的各種「假值」統一成 `False`。 |
| **`is True` vs `== True`** | `is True` 要求「就是 True 這個物件」。測試裡用 `is True` 是為了確保回傳的是**真正的 bool**，而不是「剛好為真的字串或數字」。 |

### Step 3：寫三個正規化函數，讓它變綠

新增檔案 `showme/rules.py`，**這一輪先寫到這裡**：

```python
"""純函數規則：把 agent 傳進來的參數收乾淨、把 overlay 回來的資料補完整。

這個模組刻意保持「純」：
- 不 import 專案裡任何其他模組
- 不碰瀏覽器、不碰 Session、不做 I/O
- 同樣的輸入永遠給同樣的輸出

所以它可以直接呼叫、直接測，不需要任何前置準備。
"""

from __future__ import annotations

# show_step 的 kind 白名單（design §7.3）
KINDS = ("click", "input", "select", "observe")

# page.elements 的硬上限（clarified：依 DOM 走訪順序取前 150，不分 viewport）
MAX_ELEMENTS = 150

# 每一筆元素固定就這四個鍵，一個都不能少（clarified：testid 鍵永遠存在）
ELEMENT_KEYS = ("uid", "role", "name", "testid")


def normalize_timeout_s(value: float | int | None) -> float:
    """把 timeout_s 收成秒數。

    clarified（Step_timeout_s為0或負值時如何處理）：未傳、0、負值都改用預設 120，
    不新增錯誤碼、也不立即 timeout。

    120.0 這個數字同時定義在 showme.session.DEFAULT_TIMEOUT_S；
    這裡刻意寫死而不 import，是為了讓 rules.py 保持「不相依任何模組」。
    tests/test_rules.py 有一條測試把兩邊綁在一起，走鐘會紅。
    """
    if value is None:
        return 120.0
    seconds = float(value)
    if seconds <= 0:
        return 120.0
    return seconds


def normalize_kind(kind: str | None) -> str:
    """把 kind 收成四選一。

    clarified（顯示步驟_kind不屬於四選一時是否操作失敗）：不屬於四者時視為 observe。
    大小寫不同（例如 "CLICK"）也不在白名單裡，一樣走 observe——
    這樣所有「模型亂打」的情況都落在同一條路上，行為好預測。
    """
    if kind in KINDS:
        return kind
    return "observe"


def expect_text_missing(kind: str, expect_text: str | None) -> bool:
    """observe（含由非法 kind 轉入的）卻沒給 expect_text 時回 True。

    呼叫端看到 True 就回 error="expect_text_required"，而且不畫、steps_shown 不加。
    """
    if normalize_kind(kind) != "observe":
        return False
    return expect_text is None or expect_text == ""
```

```python
def build_page(raw: dict, url: str, title: str) -> dict:
    """把 overlay 回的原始 snapshot 補成一份標準 Page。

    raw 是 window.__showme.snapshot(n) 的回傳：{"elements": [...], "truncated": bool}
    url 與 title 由 Python 這邊補（page.url、await page.title()）。

    做三件事（clarified）：
    1. 只留前 MAX_ELEMENTS（150）筆，依 overlay 給的（＝DOM 走訪）順序，不分 viewport。
    2. 每筆只保留 ELEMENT_KEYS 四個鍵；缺的補空字串——但 uid 缺就不補，
       因為 uid 是 overlay 負責組的，我們不該發明一個。
    3. truncated＝overlay 說截斷了，或原本筆數就超過 150。
    """
    raw_elements = raw.get("elements") or []

    elements = []
    for item in raw_elements[:MAX_ELEMENTS]:
        element = {}
        for key in ELEMENT_KEYS:
            if key in item:
                element[key] = item[key]
            elif key != "uid":
                element[key] = ""
        elements.append(element)

    truncated = bool(raw.get("truncated")) or len(raw_elements) > MAX_ELEMENTS

    return {"url": url, "title": title, "elements": elements, "truncated": truncated}


def uid_in_page(uid: str, page: dict | None) -> bool:
    """uid 是不是這份 page 裡某一筆元素的 uid。

    還沒拍過 page（None）一律 False；呼叫端會回 uid_not_in_snapshot 並附一份新鮮 page。
    """
    if page is None:
        return False
    return any(element.get("uid") == uid for element in page.get("elements", []))


def empty_page() -> dict:
    """一份鍵齊全但沒有元素的 Page。

    每次都回新的 dict，呼叫端改它不會污染下一次。
    """
    return {"url": "", "title": "", "elements": [], "truncated": False}
```

## 9. 常見問題與排錯

| 症狀 | 原因 | 怎麼處理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'showme.rules'`（Step 5 之後還有） | 檔名或位置錯 | 必須是 `showme/rules.py`（`ls showme/` 確認），不是 `rule.py`、不是 `tests/rules.py` |
| `ImportError: cannot import name 'uid_in_page'` | 第二輪三個函數只貼了一部分 | 三個都要貼：`build_page`、`uid_in_page`、`empty_page` |
| `test_timeout_small_positive_value_is_kept` 紅，回傳 `120.0` | 條件寫成 `if not value:` 或 `if seconds < 1:` | 條件必須是 `if seconds <= 0:`；`0.2` 是合法值 |
| `test_timeout_positive_value_is_kept_as_a_float` 紅在 `isinstance` | 直接 `return value` 沒轉型 | 要 `float(value)`；`normalize_timeout_s(120)` 必須回 `120.0` 這個 float |
| `test_kind_uppercase_becomes_observe` 紅 | 寫了 `kind.lower()` | 拿掉。規格沒有要求大小寫容錯，統一走 observe 反而更好預測（而且 `None.lower()` 會爆） |
| `AttributeError: 'NoneType' object has no attribute 'lower'` | 同上 | 同上 |
| `test_build_page_cuts_151_elements...` 紅在 `truncated is False` | 只看了 `raw["truncated"]`，沒算長度 | 要 `bool(raw.get("truncated")) or len(raw_elements) > MAX_ELEMENTS` |
| `test_build_page_keeps_exactly_150_...` 紅在 `truncated is True` | 條件寫成 `>=` | 剛好 150 **不算**截斷（clarified：≤150 → false），所以是 `>` |
| `assert 1 is True` 之類的錯 | 回傳的不是真正的 bool | `truncated` 要用 `bool(...)` 包過；`uid_in_page` 用 `any(...)`（它本來就回 bool） |
| `test_build_page_does_not_invent_a_uid` 紅 | 迴圈裡對四個鍵一律補 `""` | uid 要特別跳過：`elif key != "uid":` 才補空字串 |
| `test_empty_page_returns_a_fresh_dict_each_time` 紅 | 把空 page 寫成模組層級常數再 return 它 | 每次都要在函數裡 `return {...}` 建新的 |
| `KeyError: 'elements'` | 用了 `raw["elements"]` | 用 `raw.get("elements") or []`；overlay 可能只回 `{}` |
| 想在 `rules.py` 裡 `from showme.session import DEFAULT_TIMEOUT_S` | 會讓「純函數層」相依於狀態層 | 不要。120.0 寫死在 `rules.py`，用 `test_timeout_default_is_the_same_number_as_the_session_constant` 這條測試綁住兩邊 |
| 想在 `build_page` 裡順便驗證 uid 格式 | 那是 overlay 的責任 | 不要驗。A 只給世代號 `n`，B 組字串（`docs/handoff.md`）；Python 這邊只比對「在不在清單裡」 |
