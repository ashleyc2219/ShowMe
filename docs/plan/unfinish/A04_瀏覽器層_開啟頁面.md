## 4. 名詞小抄

| 名詞 | 白話解釋 |
|---|---|
| Playwright | 一套「用程式操控瀏覽器」的函式庫。我們只用它開視窗、走頁、在頁面裡跑 JS，**不**用它幫使用者按按鈕。 |
| async API | Playwright 有同步版與非同步版。MCP 的 tool handler 本來就是 `async`，所以只能用非同步版（`playwright.async_api`）。用錯會把整個事件迴圈卡死。 |
| Browser / BrowserContext / Page | 三層：Browser 是整個瀏覽器程式；BrowserContext 像一個獨立的「無痕視窗」（有自己的 cookie 與 init script）；Page 是一個分頁。我們固定用 1 Browser → 1 Context → 1 Page。 |
| `channel="chrome"` | 叫 Playwright 用你電腦上**真的那個 Google Chrome**，而不是它自己下載的 Chromium。Demo 要 headed（人看得到）時，用真 Chrome 比較像使用者的日常。 |
| headless | 「沒有視窗」模式。跑測試時用 `headless=True`（快、CI 也能跑）；真的教學時一定是 `headless=False`，因為人要看到箭頭。 |
| Protocol | Python 的「結構型介面」。只要一個類別有這些方法名稱與簽名，就算實作了這個 Protocol，**不需要繼承**。所以 `FakeBrowser` 不用 import 任何基底類別。 |
| 例外轉譯（exception translation） | 把外部函式庫的例外，在邊界上換成自己的例外型別。這樣 `app.py` 只要認得 `NavigationFailed`，不用認識 Playwright 的 `Error`。 |
| fixture | pytest 的「測試前置準備」。用 `@pytest.fixture` 定義，測試函式把名字寫進參數就會拿到。 |
| marker | pytest 的標籤。我們用 `@pytest.mark.browser` 標「會開真瀏覽器」的測試，之後可以用 `-m "not browser"` 跳過。 |

## 6. 介面約定

### 用到（來自前面幾篇）

本篇**沒有**用到 A02／A03 的任何函式。`browser.py` 是獨立的一層：它不認識 Session，也不認識規則。這是刻意的 —— `docs/design/showme.md` §5 要求單向相依，Session 與規則在上層（`app.py`，A07 建立）。

### 提供（給後面幾篇）

```python
# showme/browser.py
OVERLAY_PATH: Path              # <repo>/overlay/overlay.js
EMIT_FUNCTION_NAME: str         # "__showme_emit"
EmitHandler = Callable[[dict], None]

class NavigationFailed(Exception): ...

class BrowserLike(Protocol):
    async def launch(self) -> None: ...
    async def is_alive(self) -> bool: ...
    async def open(self, url: str) -> None: ...          # raise NavigationFailed
    async def current_url(self) -> str: ...
    async def title(self) -> str: ...
    async def snapshot(self, n: int) -> dict: ...        # A06 實作
    async def show(self, opts: dict) -> None: ...        # A06 實作
    async def clear(self) -> None: ...                   # A06 實作
    async def done(self, text: str) -> None: ...         # A06 實作
    def set_emit_handler(self, handler: EmitHandler | None) -> None: ...   # A05 實作
    async def close(self) -> None: ...

class PlaywrightBrowser:
    def __init__(self, overlay_path: Path = OVERLAY_PATH, headless: bool = False) -> None: ...
```

- A05 會在 `launch()` 裡加 `add_init_script` 與 `expose_function`，並補上 `_on_emit`／`set_emit_handler`。
- A06 會補上 `snapshot`／`show`／`clear`／`done`。
- A07 的 `tests/fakes.py::FakeBrowser` 會照 `BrowserLike` 實作一份不開瀏覽器的替身。
- A07 的 `showme/app.py` 只 import `BrowserLike`、`NavigationFailed`、`PlaywrightBrowser`。

> **為什麼 `BrowserLike` 這一篇就寫完整？**
> 它不是實作，是**契約**。A07 的 `FakeBrowser` 與 `app.py` 都要照它寫，而 `app.py` 的 `_take_snapshot` 一開始就會呼叫 `snapshot()`。把契約分三篇長出來，只會讓 A07 拿不到穩定的形狀。Protocol 本身沒有執行成本，也不會讓任何測試變紅。

### Step 2：conftest 加 `static_server` fixture（5 分鐘）

打開 `tests/conftest.py`，改成下面這份完整內容（`anyio_backend` 是 A01 就有的，保留）：

```python
"""所有測試共用的 fixture。"""

from __future__ import annotations

import http.server
import threading
from functools import partial
from pathlib import Path

import pytest

PAGES_DIR = Path(__file__).parent / "fixtures" / "pages"


@pytest.fixture
def anyio_backend() -> str:
    """anyio 的 pytest plugin 要靠這個 fixture 決定用哪個 async 後端。"""
    return "asyncio"


@pytest.fixture(scope="session")
def static_server():
    """在 127.0.0.1 的隨機 port 上，用一條背景執行緒送出 tests/fixtures/pages/ 底下的檔案。

    yield 出來的是網址前綴，例如 "http://127.0.0.1:52341"。
    測試裡這樣用：await browser.open(f"{static_server}/dashboard.html")
    """
    handler = partial(http.server.SimpleHTTPRequestHandler, directory=str(PAGES_DIR))
    server = http.server.ThreadingHTTPServer(("127.0.0.1", 0), handler)
    thread = threading.Thread(target=server.serve_forever, daemon=True)
    thread.start()
    try:
        yield f"http://127.0.0.1:{server.server_port}"
    finally:
        server.shutdown()
        server.server_close()
```

逐句解釋：

- `("127.0.0.1", 0)` 的 `0` 表示「請作業系統給我一個沒人用的 port」。這樣同時跑多次測試也不會撞埠。真正拿到的號碼在 `server.server_port`。
- `ThreadingHTTPServer` 每個請求開一條執行緒。瀏覽器載一頁通常會同時要 HTML 與 favicon，單執行緒版本容易卡住。
- `daemon=True`：這條執行緒不會擋住 Python 結束。萬一 `shutdown()` 沒被呼叫到，程式還是能退出。
- `scope="session"`：整輪測試只起一次，省時間。
- `finally` 裡先 `shutdown()`（叫 `serve_forever` 停）再 `server_close()`（放掉 port）。

> `SimpleHTTPRequestHandler` 會把每個請求印到 stderr（像 `127.0.0.1 - - [29/Aug/2026 ...] "GET /dashboard.html HTTP/1.1" 200 -`）。pytest 預設會把 stderr 收起來，只有測試失敗時才顯示，不用特別處理。

這裡的測試會真的啟動一顆 headless 瀏覽器，所以標了 browser marker：

from __future__ import annotations

import pytest

from showme.browser import NavigationFailed, PlaywrightBrowser

pytestmark = [pytest.mark.anyio, pytest.mark.browser]


@pytest.fixture
async def browser():
    """每個測試給一顆乾淨的 headless 瀏覽器，測完一定關掉。"""
    b = PlaywrightBrowser(headless=True)
    await b.launch()
    try:
        yield b
    finally:
        await b.close()


async def test_launched_browser_is_alive(browser):
    assert await browser.is_alive() is True


async def test_open_static_page_reports_url_and_title(browser, static_server):
    await browser.open(f"{static_server}/dashboard.html")

    assert await browser.current_url() == f"{static_server}/dashboard.html"
    assert await browser.title() == "Dashboard"


async def test_open_unreachable_url_raises_navigation_failed(browser):
    with pytest.raises(NavigationFailed):
        await browser.open("http://localhost:1")


async def test_is_alive_is_false_after_close(browser):
    await browser.close()

    assert await browser.is_alive() is False

說明：

- `pytestmark = [pytest.mark.anyio, pytest.mark.browser]` 一次幫這個檔裡**每個**測試貼兩個標籤：`anyio`（讓 async 測試真的被跑）與 `browser`（可被 `-m` 篩選）。
- `browser` 這個 fixture 是 **async generator fixture**：`yield` 之前是準備、之後是收尾。anyio 的 pytest plugin 支援它，前提是使用它的測試有 `anyio` marker —— 我們有。
- `test_is_alive_is_false_after_close` 裡自己先 `close()` 了一次，fixture 收尾時會再 `close()` 一次。我們的 `close()` 設計成**可以重複呼叫**，第二次什麼都不做。
- `http://localhost:1` 是「一定沒人在聽」的 port（1 號 port 需要 root 且沒人會拿來跑 HTTP）。這正是 `開始教學.feature` 裡 `navigation_failed` 那條 Example 用的網址。

### Step 4：寫 `showme/browser.py`（15 分鐘）

新增 `showme/browser.py`，完整內容如下：

```python
"""Playwright 瀏覽器層：ShowMe 唯一碰瀏覽器的檔案。

上層（showme/app.py）只依賴 BrowserLike 這個介面，所以測試可以換成
tests/fakes.py 的 FakeBrowser，不必真的開瀏覽器。

本檔在 A04 建立（開頁），A05 補注入與 emit 橋，A06 補四個 JS 呼叫。
"""

from __future__ import annotations

from pathlib import Path
from typing import Callable, Protocol

from playwright.async_api import async_playwright

OVERLAY_PATH = Path(__file__).resolve().parent.parent / "overlay" / "overlay.js"
EMIT_FUNCTION_NAME = "__showme_emit"
EmitHandler = Callable[[dict], None]


class NavigationFailed(Exception):
    """page.goto 丟錯時由 open() 轉成這個。"""


class BrowserLike(Protocol):
    """app.py 只依賴這個介面；真的 PlaywrightBrowser 與測試用 FakeBrowser 都實作它。"""

    async def launch(self) -> None: ...
    async def is_alive(self) -> bool: ...
    async def open(self, url: str) -> None: ...
    async def current_url(self) -> str: ...
    async def title(self) -> str: ...
    async def snapshot(self, n: int) -> dict: ...
    async def show(self, opts: dict) -> None: ...
    async def clear(self) -> None: ...
    async def done(self, text: str) -> None: ...
    def set_emit_handler(self, handler: EmitHandler | None) -> None: ...
    async def close(self) -> None: ...


class PlaywrightBrowser:
    def __init__(self, overlay_path: Path = OVERLAY_PATH, headless: bool = False) -> None:
        self.overlay_path = overlay_path
        self.headless = headless
        self.page = None        # playwright Page；測試會直接用它 evaluate
        self._pw = None
        self._browser = None
        self._context = None
        self._emit_handler: EmitHandler | None = None

    async def launch(self) -> None:
        self._pw = await async_playwright().start()
        try:
            self._browser = await self._pw.chromium.launch(
                channel="chrome", headless=self.headless
            )
        except Exception:
            self._browser = await self._pw.chromium.launch(headless=self.headless)
        self._context = await self._browser.new_context()
        self.page = await self._context.new_page()

    async def is_alive(self) -> bool:
        if self.page is None or self._browser is None:
            return False
        return not self.page.is_closed() and self._browser.is_connected()

    async def open(self, url: str) -> None:
        try:
            await self.page.goto(url)
        except Exception as exc:
            raise NavigationFailed(str(exc)) from exc

    async def current_url(self) -> str:
        return self.page.url

    async def title(self) -> str:
        return await self.page.title()

    async def close(self) -> None:
        for closeable in (self._context, self._browser):
            if closeable is None:
                continue
            try:
                await closeable.close()
            except Exception:
                pass
        if self._pw is not None:
            try:
                await self._pw.stop()
            except Exception:
                pass
        self.page = None
        self._context = None
        self._browser = None
        self._pw = None
```

| 這一行 | 官方依據 |
|---|---|
| `await async_playwright().start()` | 不用 `async with` 而是自己 `start()`／`stop()`，是官方給「不是一次跑完的程式」（REPL、長駐 server）的用法。ShowMe 是長駐的 MCP server，所以必須這樣寫。<br>來源：https://playwright.dev/python/docs/api/class-playwright |
| `chromium.launch(channel="chrome", headless=...)` | `channel` 可為 `"chrome"`、`"msedge"` 等，指定用系統上安裝的瀏覽器。<br>來源：https://playwright.dev/python/docs/browsers |
| `except Exception:` 後不帶 channel 再 launch 一次 | 機器上沒有那個 channel 時 `launch` 會丟 `playwright.async_api.Error`（所有 Playwright 例外的基底類別）。退回不帶 `channel`，就用 `playwright install chromium` 下載的內建 Chromium。<br>來源：https://playwright.dev/python/docs/api/class-error |
| `browser.new_context()` → `context.new_page()` | 官方建議的三層結構。**一定要有 Context**：A05 的 `add_init_script` 與 `expose_function` 都掛在 Context 上，掛在 Page 上就不能跨頁。<br>來源：https://playwright.dev/python/docs/browser-contexts |
| `page.goto(url)` 會丟例外 | 官方明說：SSL 問題、網址無效、逾時、連不到伺服器會丟錯；**但 404／500 這種正常 HTTP 狀態碼不丟錯**（仍算導航成功）。這正好是規格要的：`navigation_failed` 只在真的開不了時發生。<br>來源：https://playwright.dev/python/docs/api/class-page |
| `page.is_closed()` / `browser.is_connected()` | 兩個同步方法（不用 await），各回一個 bool。<br>來源：https://playwright.dev/python/docs/api/class-page 、https://playwright.dev/python/docs/api/class-browser |
| `playwright.stop()` | 對應 `start()`，關掉底層的 node 子行程。<br>來源：https://playwright.dev/python/docs/api/class-playwright |

**幾個刻意的設計選擇：**

- `except Exception` 而不是 `except Error`：範圍寬一點，避免不同版本丟不同型別時 fallback 失效。代價是「Chrome 存在但因別的原因起不來」時也會退到 Chromium —— 那樣通常第二次也會失敗，而且會丟出**原始的**錯誤訊息給你看，不會被吃掉。
- `open()` 把例外轉成 `NavigationFailed(str(exc))`：`app.py` 只要 `except NavigationFailed` 就好，不用 import Playwright。錯誤碼 `navigation_failed` 的字串是 A08 在 `app.start_tutorial` 裡寫的，**不在這一層**。
- `close()` 每一步都包 try/except 並吞掉：關瀏覽器失敗不該讓 `end_tutorial` 或程式結束變成錯誤。最後把四個欄位設回 `None`，所以 `close()` 可以重複呼叫，而且 `is_alive()` 會回 `False`。
- `is_alive()` 是 `async` 但裡面沒有 `await`：這是為了讓 `FakeBrowser` 與它同形狀（`BrowserLike` 要求 `async def is_alive`）。多一個 `async` 不會有效能問題。

### Step 6：手動用眼睛看一次（5 分鐘）

自動測試都是 headless（沒有視窗）。這一片（S1）的驗收是「**視窗出現目標頁**」，所以要用眼睛確認一次。

新增 `scripts/dev_open.py`：

```python
"""手動驗證用：開一個 headed 瀏覽器、走到指定 url、停 10 秒再關。

用法：
    uv run python scripts/dev_open.py http://localhost:3000
    uv run python scripts/dev_open.py https://example.com
"""

from __future__ import annotations

import asyncio
import sys

from showme.browser import NavigationFailed, PlaywrightBrowser


async def main(url: str) -> int:
    browser = PlaywrightBrowser(headless=False)
    await browser.launch()
    try:
        await browser.open(url)
    except NavigationFailed as exc:
        print(f"navigation_failed: {exc}")
        await browser.close()
        return 1
    print(f"opened : {await browser.current_url()}")
    print(f"title  : {await browser.title()}")
    print("視窗會停留 10 秒，請用眼睛確認畫面。")
    await asyncio.sleep(10)
    await browser.close()
    return 0


if __name__ == "__main__":
    if len(sys.argv) != 2:
        print("用法：uv run python scripts/dev_open.py <url>")
        raise SystemExit(2)
    raise SystemExit(asyncio.run(main(sys.argv[1])))
```

跑跑看（用一個一定開得起來的網址；沒有網路的話先開 demo app 或用 `file://`）：

```bash
uv run python scripts/dev_open.py https://example.com
```

預期：**跳出一個真的 Chrome 視窗**，顯示 Example Domain，10 秒後自己關掉。終端機印：

```text
opened : https://example.com/
title  : Example Domain
視窗會停留 10 秒，請用眼睛確認畫面。
```

再故意打一個開不起來的：

```bash
uv run python scripts/dev_open.py http://localhost:1
```

預期：視窗會開（因為 `launch` 成功了），但終端機印出並以 exit code 1 結束：

```text
navigation_failed: Page.goto: net::ERR_CONNECTION_REFUSED at http://localhost:1/
Call log:
  - navigating to "http://localhost:1/", waiting until "load"
```

（訊息細節依 Playwright 版本略有不同，重點是前綴 `navigation_failed:`。）

## 9. 常見問題與排錯

| 症狀 | 原因 | 怎麼處理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'showme.browser'` | 檔案沒建、或建在錯的資料夾 | 確認路徑是 `showme/browser.py`（不是 `tests/` 底下），且你在 repo 根目錄跑 pytest。 |
| `Executable doesn't exist at .../chrome-linux/headless_shell`（或類似的 `playwright install` 提示） | 沒有系統 Chrome，fallback 到內建 Chromium，但 Chromium 沒下載 | `uv run playwright install chromium`。 |
| 測試卡住不動，60 秒後被 pytest-timeout 砍掉 | `goto` 等待某個永遠不會結束的資源；或 `static_server` 沒起來 | 先單獨跑 `uv run pytest -m browser -q -k unreachable`。若是 `static_server` 的問題，檢查 `tests/fixtures/pages/` 底下真的有 `dashboard.html`。 |
| `fixture 'anyio_backend' not found` | `tests/conftest.py` 被覆蓋掉了 | 把 Step 2 那份完整 conftest 貼回去（`anyio_backend` 必須留著）。 |
| 測試拿到的 `browser` 是一個 `async_generator` 物件，`await browser.is_alive()` 報 `AttributeError` | 該測試缺 `anyio` marker，async fixture 沒被展開 | 確認檔案最上面有 `pytestmark = [pytest.mark.anyio, pytest.mark.browser]`。 |
| `PytestUnknownMarkWarning: Unknown pytest.mark.browser` | `pyproject.toml` 的 `[tool.pytest.ini_options]` 少了 `markers` | 補上 §3 那段設定。 |
| `title()` 回空字串 | 開到的不是 `dashboard.html`（例如打錯路徑拿到 404 頁） | 印一下 `await browser.current_url()`；注意 `goto` **不會**因為 404 丟錯，所以路徑打錯時測試會以「title 不對」的形式失敗。 |
| headed 視窗一閃就不見 | 腳本跑完就 `close()` 了 | 這是預期行為；`dev_open.py` 會停 10 秒，想久一點就把 `asyncio.sleep(10)` 的數字改大。 |
| `RuntimeError: Event loop is closed`（測試結束時） | `close()` 沒被呼叫，Playwright 的背景資源沒收乾淨 | 確認 fixture 的 `finally: await b.close()` 有寫。 |
